# 변경 기록(한국어)

CHANGELOG.md의 한국어 번역입니다. 제목은 영어판과 같으며 변경 사항마다 한 줄로 기록합니다. 번역되지 않은 릴리스는 영어로 표시합니다.

## 2.1.0 (2026-11-12)
- 메뉴에 백업 전용 페이지를 추가했습니다. 저장 폴더, 실행 시 백업, 지금 백업을 모으고 백업을 두 열로 표시합니다.
- 일반 백업: 슬라이더로 보관 개수를 2~20개(기본값 6개)로 설정합니다. 가장 오래된 백업은 다음 백업 이후에만 삭제합니다(EstusFlask님 감사합니다).
- 개인 백업: 녹색 화살표로 옮기면 앱이 삭제하지 않으며 보관 개수에도 포함되지 않습니다. 빨간 화살표로 되돌립니다.
- 각 백업에 '최종 보스 직전' 같은 메모를 추가할 수 있으며 지금 백업 옆에도 메모 입력란이 있습니다.
- 필요 없는 백업은 확인 후 삭제할 수 있습니다.
- 메뉴를 더 간결하게 만들고 페이지 제목 아래 설명을 없앴으며 앱 정보의 제목을 버전 번호로 바꿨습니다.

## 2.0.0 (2026-11-11)
- 하나의 앱에서 여러 게임을 지원합니다. Black Myth: Wukong, Phantom Blade Zero와 함께, 출시 전에 외형을 미리 볼 수 있는 Stellar Blade: Blood Rain을 추가했습니다.
- 처음 시작할 때나 제목 표시줄의 게임 전환으로 게임을 선택합니다. 설정에서 매번 선택하도록 할 수 있으며 선택 화면에 개발자의 메시지도 있습니다.
- 각 게임에 전용 외형, 그림, 카드를 적용했습니다. 앱 아이콘은 모드 더미 모양으로 바뀌었으며 업데이트 직후 Windows에 표시됩니다.
- Black Myth: Wukong: pak, UE4SS 및 C# Loader 모드를 지원합니다. C# Loader와 UE4SS를 한 번 클릭하여 설치하고 저장 데이터를 백업할 수 있습니다.
- 게임 실행 오른쪽에 실행 옵션을 추가했습니다. Wukong의 pak 모드용 -fileopenlog처럼 게임에 권장되는 인수를 설정할 수 있습니다.
- 시계 옆 트레이 아이콘에서 게임을 전환하거나 실행할 수 있습니다. 설정에서 최소화와 닫기 동작을 트레이로 보내도록 바꿀 수 있습니다.
- 원하는 게임이 없다면 게임 선택 화면에서 게임 폴더를 스캔하여 Discord에 공유할 보고서를 만들 수 있습니다. 사용자 이름과 ID는 숨깁니다.
- 게임 선택 카드에 이 PC의 게임 위치와 모드 개수를 표시합니다.
- 처음 시작할 때 언어 질문을 게임 선택보다 먼저 표시하며, 게임 선택 화면에도 언어 선택기를 추가했습니다.
- 설치 확인 화면에 모드를 설치할 게임 이름을 표시합니다.
- 수동으로 설치한 UE4SS가 이미 최신 빌드이면 더 이상 업데이트를 안내하지 않습니다.
- 모든 게임에 공통 다운로드 uemm_<version>.zip을 사용합니다. 이전 앱 버전에서도 업데이트를 찾을 수 있습니다.

## 1.7.2 (2026-11-10)

- 확인 중에는 버튼이 녹색으로 회전하며 최소 1초간 표시되므로 클릭 반응을 확인할 수 있습니다.
